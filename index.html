Güvenlik ve gizlilik

Bu tek HTML dosyası tarayıcıda çalışır. Tarayıcıya girilen API anahtarı, istek sırasında sağlayıcıya gönderilir; kaynak kodunu ve ağ trafiğini inceleyebilen kişiler anahtarı görebilir.

Daha güvenli yayın için API anahtarlarını sunucu tarafında saklayan küçük bir backend/proxy kullan. Bu sayfa anahtarları yalnızca sessionStorage içinde tutar; kalıcı depolama yapmaz.

Sağlayıcı araştırma desteği

Her sağlayıcı araştırma görevini yerine getirecek şekilde istem alır. Ancak gerçek zamanlı web araması, arama aracı etkinleştirildiğinde ve ilgili API bunu desteklediğinde çalışır.

Gemini: Google Search grounding etkinleştirilmeye çalışılır. Claude: web_search aracı için sunucu/hesap desteği gerekebilir. OpenAI: web_search aracı Responses API üzerinden sunulabilir. DeepSeek ve NVIDIA: model/API uç noktası tek başına web taraması sağlamaz; ayrı arama servisi veya backend entegrasyonu gerekir. Bu prototip desteklenmeyen arama araçlarını taklit etmez.

Not: API anahtarı girilmesi sağlayıcı hesabında web aramasının otomatik olarak açık olduğu anlamına gelmez. Sağlayıcı erişimi, model adı, kota, CORS ve arama aracı izinleri bağlantıyı etkileyebilir.
